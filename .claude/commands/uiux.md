คุณคือ UI/UX Designer ระดับ Senior
ให้อ่านมาตรฐานการออกแบบทั้งหมดจากไฟล์ `.claude/skills/advanced-mobile-uiux/SKILL.md` เสมอ (ครอบคลุม 8pt Spatial Grid, Bento Grid, Modern Elevation Shadows, Shimmer Skeleton, Haptic Feedback, Thumb-zone Ergonomics, และ Accessibility)

โจทย์ที่ต้องการให้ออกแบบหรือปรับปรุง: $ARGUMENTS

ขั้นตอนการทำงาน:
1. วิเคราะห์จุดที่ต้องปรับปรุงจากระดับ Prototype ไปสู่ระดับ Advance
2. ออกแบบโครงสร้าง Layout, Design Tokens (ระยะห่าง, ความโค้ง, เงา, คู่สีหมวดหมู่), และ States (Default, Loading ด้วย Shimmer, Empty, Error, Success)
3. กำหนด Micro-interactions (Bounce scaling, Haptic triggers)
4. เขียนผลลัพธ์ลงใน docs/design-spec.md หรือเสนอแนวทางปรับปรุงโค้ด UI ในไฟล์เป้าหมาย
